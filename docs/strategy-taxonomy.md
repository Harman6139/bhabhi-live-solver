# Strategy Taxonomy

Status: Phase 0 candidate registry. Unless marked **required correctness**, every
entry is an unvalidated hypothesis. Phase 6 must run the listed experiment or a
documented replacement, record artifact paths, add discovered counterexamples,
and decide whether the motif is retained.

Evidence labels:

- **Required correctness** — consequence fixed by rules or `GOAL.md`; still
  requires a passing test.
- **Reported** — appears in a cited community/rules source, without project
  validation.
- **Hypothesis — unrun** — plausible and preregistered; no result yet.
- **Experimental** — reserved for a stored, reproducible project result.

files or results already exist.

## Phase 6 completion procedure

For every retained motif:

1. store the exact fixture generator, seeds, rules, and solver configuration;
2. store raw action values and terminal outcomes;
3. record counterexamples or the searched boundary;
4. mark the evidence as experimental only after the command has actually run;
5. connect any production feature to an ablation showing terminal, calibration,
   robustness, or required-correctness value.
